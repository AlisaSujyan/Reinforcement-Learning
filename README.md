# Tic-Tac-Toe
This is a basic implementation of the classic Tic-Tac-Toe game where two players take turns marking X and O on a 3x3 grid. 
The game continues until one player wins, or the grid is filled, resulting in a draw.
It is a great beginner project for understanding the logic behind game development and the interaction between user inputs and game state management.
The main goal is making an RL player who will never lose.
